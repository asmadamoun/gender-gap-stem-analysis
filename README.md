# Gender Gap in STEM: An Exploratory Data Analysis

## About this project
This project looks at how the share of bachelor's degrees awarded to women in the USA changed from 1970 to 2011, with a focus on STEM fields.

## Data
- Dataset: *Percentage of Bachelor's degrees done by women USA* (Kaggle, uploaded by Yogesh Kumar Singla)
- Original data compiled by Randal Olson from U.S. Department of Education statistics
- Link:  [Kaggle dataset](https://www.kaggle.com/datasets/yogeshkumarsingla/percentage-of-bachelors-degrees-done-by-women-usa)
  
## Tools
Python, pandas, Matplotlib

## Key findings
- **Biology**: The share of women went up from about 29% in 1970 to about 60% in the early 2000s.
- **Engineering**: It started very low (about 1% in 1970) and grew to about 17-18%.
- **Computer Science**: It rose from about 14% in 1970 to about 37% in the mid-1980s, then fell to about 18% in 2011.
